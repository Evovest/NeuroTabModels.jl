Benchmarks ​

Each dataset has a report that fits MLP, ResNet, NeuroTree and TabM with fixed settings and scores them on a held-out test set. Every report run adds its scores to quarto/benchmarks/results.csv, tagged with the NeuroTabModels version and git commit.

This page shows, for each dataset, the test scores and timings of the latest version, with the change from the previous version in brackets. A version run more than once counts with its latest run. Timings leave out compilation but depend on the machine, so runs are meant to be made on the same one.

To add a run, render the reports with julia --project=quarto quarto/benchmarks/run.jl followed by the datasets. Add a dataset as a new entry in DATASETS in quarto/benchmarks/benchmarks.jl.
